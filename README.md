# UOFs Library

A Rust implementation of the **UFOs** multivariate signature scheme based on the paper:  
👉 [IACR Cryptology ePrint Archive: Report 2026/1607](https://eprint.iacr.org/2026/1607)

## ⚠️ Warning

This implementation is experimental and **does not yet have the necessary status for production use!** Use it at your own risk.
